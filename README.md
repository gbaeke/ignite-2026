# Microsoft Ignite 2026 — Opening Keynote Notes

Notes on the [Microsoft Ignite 2026 opening keynote](https://www.youtube.com/watch?v=ZR4v1c4CClc) (2:25:50, November 2026): a summary of what was announced, and a map of every technology mentioned with links to its documentation.

## Contents

- **[Keynote summary](ignite-2026-opening-keynote-summary.md)**: a TL;DR and a walkthrough of each segment of the keynote, with frames from the video. Each ▶ timestamp opens the video at that moment.
- **[Technologies & documentation map](ignite-2026-technologies-and-docs.md)**: every product, feature and model named in the keynote, with what it is, its status and links to the docs (Microsoft Learn first). Researched on 2026-11-18.
- **[ignite-keynote.html](ignite-keynote.html)**: the summary as a single web page. Open it locally in a browser; it loads its images from `frames/`.

## Notes

- `frames/` holds stills taken from the keynote video, which the summary and the HTML page use.
- The keynote video and its content belong to Microsoft. This repo doesn't include the video or the full transcript. Watch the keynote [on YouTube](https://www.youtube.com/watch?v=ZR4v1c4CClc).
- Product statuses change quickly. Check the linked docs before relying on one.
